# VisualStudio Code Extension

## Install
- cp VsCodeExtension ~/.vscode/extensions/local.VsCodeExtension
- ln --symbolic VsCodeExtension ~/.vscode/extensions/local.VsCodeExtension
- restart VsCode
- check if it appears in Extensions (`Ctrls+Shif+X`)

## Functionality
- selectedDir.path
- selectedDir.name
- selectedDir.run

## Usage
- can be used in tasks.json
